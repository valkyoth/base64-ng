# Protocol And Interoperability Registry

`v1/` freezes every specialized protocol/configuration claim planned for the
2.0 release. The registry binds public surfaces to locked standards, errata,
requirement ledgers, finite-limit types, API snapshots, retained corpus cases,
independent grammar models, and external implementations.

The runner is verification tooling and is not published. Run:

```sh
scripts/check-protocol-registry.sh
```

Registry changes require a numbered review commit, regenerated hashes, and an
external protocol/provenance pentest.
