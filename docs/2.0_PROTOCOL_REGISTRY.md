# 2.0 Protocol And Interoperability Registry

Commit 49 freezes specialized protocol and named Base64 configuration claims
under `protocol-registry/v1/`. The registry is release evidence, not a runtime
API and not part of any published package.

## Coverage

`protocols.tsv` maps the MIME body, RFC 7468 textual encoding, Base64-family
multibase, IMAP modified-Base64 payload, Passlib PBKDF2 record, SHA-crypt
record, and OpenPGP armor claims to:

- an exact specification publication or source snapshot;
- a reviewed errata snapshot and requirement ledger;
- positive and negative corpus entries;
- the public finite-limit type;
- two independent implementations; and
- the complete 2.0-development public API snapshot for its package.

`configurations.tsv` separately inventories every exported strict, body,
alphabet, padding-compatibility, and trailing-bit compatibility constant in
the core. The validator derives that public-name set from Rust source and
fails if a new or renamed constant is not registered.

## Corpus And Independence

Every `cases.tsv` entry is hex encoded and binds its decision to the SHA-256
of the exact source and errata bytes plus one or more requirement-ledger IDs.
The dedicated runner evaluates companion cases twice:

1. `model.rs` uses deliberately small grammar and Base64 models and imports no
   production crate or external Base64 implementation.
2. `production.rs` invokes the public companion API with finite limits.

`references.rs` separately compares core configuration behavior with exactly
pinned `base64` 0.23.0 and `base64ct` 1.8.3 releases. Keeping independent
models, production dispatch, and external references in separate modules
prevents the oracle from becoming a wrapper around the implementation under
test.

## Provenance

`provenance.tsv` records implementation versions or snapshots, licenses,
roles, and reproduction entry points. Exact upstream vector/source bytes are
retained under `rfc/`, `spec/multibase/`, and `spec/password/`. Live external
tool versions remain recorded by focused interoperability jobs; they do not
silently rewrite the retained corpus.

Run the complete offline and differential gate with:

```sh
scripts/check-protocol-registry.sh
```

The mutation suite proves that protocol removal, public-name drift, corpus
decision changes, source-byte changes, and production imports in the
independent model all fail closed.
