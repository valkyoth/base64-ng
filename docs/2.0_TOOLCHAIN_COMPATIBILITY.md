# 2.0 Toolchain Compatibility

Status: Commit 5 compatibility contract for the 2.0 development line.

Rust 1.90.0 is the fixed 2.0 MSRV. Development and release evidence use the
active pinned stable compiler, while `scripts/check-2.0-msrv.sh` separately
checks the supported capability matrix with Rust 1.90.0.

The host matrix covers default, allocator-free, `alloc`, `std`, `stream`,
`simd`, `secrets`, `checked-backend`, combined secret/SIMD, all-feature, every
current companion crate, and the semantic-corpus runner. Target CI repeats the
allocator-free SIMD/secret combination on:

- `x86_64-unknown-linux-gnu`
- `aarch64-unknown-linux-gnu`
- `x86_64-unknown-freebsd`
- `wasm32-unknown-unknown`
- `thumbv7em-none-eabihf`

No Commit 5 implementation requires a compiler newer than Rust 1.90.0.
The const and runtime validated-alphabet constructors, compile-pass/fail
harnesses, exhaustive mapping tests, and `no_std` representation checks run
under that toolchain through `scripts/check-2.0-alphabet.sh`.
`std::arch` optimizations unavailable at the MSRV remain behind existing
target/toolchain gates and retain the scalar implementation. Later numbered
commits must record any newer-toolchain optimization here together with its
Rust 1.90-compatible implementation or fallback.
