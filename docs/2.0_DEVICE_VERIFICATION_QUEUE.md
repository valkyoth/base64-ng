Target: M2 MacBook Pro, native `aarch64-apple-darwin`.

```sh

scripts/check_wasm_browser_safari_dispatch.sh
```

Record the commit hash, macOS version, `rustc -Vv`, and the final `ok` lines.
The Safari command carries forward Commit 16's WebKit evidence; it is not a
Commit 17 hardware-acceleration requirement.

## AArch64 Linux

Target: AWS Graviton or equivalent real AArch64 Linux host.

```sh
scripts/check_aarch64_linux.sh
scripts/check-2.0-profiles.sh
```

Record the instance CPU, kernel, `rustc -Vv`, and final `ok` lines. This pass
checks portability and admitted pre-2.0 backend compatibility; Commit 17 adds
no new accelerated profile backend.
